# Testo dimostrativo

`il-faro.md` è un testo sintetico creato con assistenza AI per questa distribuzione, senza usare racconti o profili di voce personali. È incluso nella licenza del progetto.

Serve a provare importazione, conteggi, controlli e percorso delle skill. Non è un modello di stile né un benchmark della qualità letteraria.

Per una lettura a freddo usa una chat nuova. Non chiedere di calibrare la tua voce su questo esempio.
